Personal project · Personal finance

PocketChange

A clearer view of your money.

A local-first Electron app for tracking net worth, understanding spending, and planning investments. An XLSX-backed database and shared financial model turn records stored on your device into useful analysis.

Platform
Desktop
Built with
Electron, JavaScript, HTML & CSS

From account balances to the bigger picture

The net-worth overview shows the total; account composition explains what changed beneath it. Cash, investments, and debt remain visible as separate parts of the same history rather than disappearing into a single balance.

The data model stores dated account balances separately from individual transactions and current investment holdings. That distinction lets the interface show how account values evolve without treating today's holdings as a historical record.

Understand a month. Compare the pattern.

Daily spending and category breakdowns answer different questions from a multi-month comparison. The interface provides both: a detailed view of one month and a longer view of income, spending, and savings, with category filters and mean and median statistics.

Both views use the same database-backed definition of liquid income. Category settings determine which income counts toward liquid savings, so the calculation stays consistent across breakdowns and comparisons instead of being redefined by each chart.

A workbook behind a database interface

Transactions, accounts, balances, and investment holdings live in separate sheets of a local XLSX workbook. The application accesses them through a database abstraction with entity validation and relationship handling, rather than coupling each screen to spreadsheet operations.

Electron's preload bridge exposes specific IPC operations for file selection and database access. This keeps the renderer focused on the interface while the desktop layer handles local files, and leaves room to replace the storage implementation without redesigning every view.

Financial rules beneath the charts

Holdings connect accounts to assets with explicit valuation rules: shares multiplied by price determine value when both are supplied. Accounts and assets cannot be deleted while holdings still reference them, keeping the relationships behind the analysis intact.

Allocation targets are scoped to either an account or the whole portfolio and normalized into weights when read. The contribution planner builds on those holdings and targets to show how proposed purchases would change the allocation before a plan is applied.

Demo data is synthetic; investment prices are illustrative.
