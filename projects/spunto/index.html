Spunto

Tasks and calendar, together.

A hosted React Native and Expo application bringing tasks, events, and habits into one workspace. I use Spunto every day to drive my productivity, with shared data across views, Supabase-backed persistence, and careful handling of calendar dates.

Platform
Mobile & web
Built with
React Native, Expo, Supabase

Tasks, calendar, and context

Tasks and events share a calendar without losing their different semantics: a task can be completed, an event occupies time, and an all-day item belongs to a date rather than a time slot.

Typed Supabase queries and React Query mutation invalidation keep the task list and calendar backed by the same persisted records. React Native and Expo provide the application foundation for mobile and web, rather than treating the web companion as a separate product.
