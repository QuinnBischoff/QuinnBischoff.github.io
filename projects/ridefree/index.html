Personal project · Indoor cycling

RideFree

Indoor training, on your terms.

An indoor cycling app connecting a React interface to smart-trainer hardware through Web Bluetooth. Workout timing, target power, device measurements, and ride controls come together in a browser-based training experience.

Platform
Web
Built with
React, Firebase, Web Bluetooth

From browser UI to trainer control

The device layer uses Web Bluetooth to subscribe to cycling-power measurements and send target-power commands through the Fitness Machine Control Point. That means decoding binary notifications and encoding watt targets, not just displaying a timer.

The ride lifecycle handles pause, resume, interval skips, and intensity changes. Completion keeps the trainer connected for cooldown; leaving an active ride asks for confirmation before disconnecting. These transitions matter as much as the happy path when software controls hardware.

Turning workout stages into a ride

A structured workout has to make sense in the editor, the preview chart, and during execution. Stages describe duration and target power, while intensity adjustments scale targets across both work and recovery intervals.

The power profile renders ramps continuously and changes color at the exact power-zone boundaries. The editor makes those details visible as stages are changed, repeated, and reordered, so the preview communicates the workout before a trainer is connected.

Demo rider settings are fictional; ride telemetry is simulated.
